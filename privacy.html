Política de privacidad

Última actualización: 18 de noviembre de 2026

Qué datos se usan

  • Tokens de acceso de las cuentas que el usuario autoriza (TikTok, Instagram, YouTube): se guardan solo en la computadora del usuario y se usan únicamente para publicar los clips que él genera.
  • Información básica de la cuenta (por ejemplo, opciones de privacidad disponibles para publicar), leída de las APIs oficiales al momento de publicar.
  • Videos y textos de los clips, que se envían solo a las cuentas del usuario.

Qué no se hace

  • No hay servidor ni base de datos: nada se envía a terceros fuera de las APIs oficiales.
  • No se venden, comparten ni analizan datos de usuarios o seguidores.
  • La página de autorización solo muestra la dirección de retorno en el navegador; no la guarda.

Cómo borrar los datos

Borrando la carpeta .tokens del programa y revocando el acceso de la app desde la configuración de cada red social.

Contacto

A través de GitHub: github.com/fedbi.

Summary (English)

autoclip stores access tokens only on its user's own computer and uses them solely to post that user's clips to their own accounts. There is no server or database, and no data is sold, shared or sent anywhere other than the official platform APIs. Delete the .tokens folder and revoke the app in each platform's settings to remove all data.
